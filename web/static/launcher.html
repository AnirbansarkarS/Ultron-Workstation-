Gesture Guide

Use hand gestures once the workspace is running. Press [M] to switch between Voxel and Model control modes.

☝️
Pointer
Draw / place voxel
🤏
Pinch
Erase voxel / Grab model
✋
Open Palm
Rotate camera / Rotate model
✊
Fist
Hold / freeze
🖐️🖐️
Two Hands
Scale model / zoom

Keyboard shortcuts (while workspace is running):

[M] Toggle VOXEL ↔ MODEL mode [O] Open file picker [R] Reset model transform [ESC] Quit workspace
